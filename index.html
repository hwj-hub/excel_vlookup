            자주 묻는 질문

            VLOOKUP 함수는 어떻게 쓰나요?

            =VLOOKUP(찾을 값, 찾을 범위, 열 번호, FALSE) 네 칸입니다. 찾을 범위의 첫 열에서 찾을 값을 찾아, 그 줄에서 열 번호째 칸을 가져옵니다. 범위는 $A$2:$D$100 처럼 $ 로 묶어야 아래로 채울 때 밀리지 않고, 마지막은 꼭 FALSE(또는 0)여야 정확히 같은 값만 찾습니다. 두 표를 넣으면 이 도구가 실제 시트 이름·열·줄 번호를 넣은 수식을 만들어 줍니다.

            값이 분명히 있는데 #N/A 가 나와요.

            대부분 눈에 안 보이는 차이입니다. 가장 흔한 것은 끝에 붙은 공백, 글자로 저장된 숫자(칸 왼쪽 위 초록 삼각형), 웹·메신저에서 복사해 온 줄 없는 공백, CSV 를 열며 빠진 앞자리 0 입니다. 두 표를 넣으면 「#N/A 원인」 카드에 줄마다 어떤 차이인지와 고치는 수식(TRIM·SUBSTITUTE·VALUE 등)을 보여 줍니다. 엑셀의 TRIM 은 웹에서 온 줄 없는 공백(CHAR(160))은 지우지 못합니다.

            가져온 값이 빈칸이어야 하는데 0 이 나와요.

            VLOOKUP·XLOOKUP 은 찾은 칸이 비어 있으면 0 을 돌려줍니다. 수식으로는 =IF(VLOOKUP(…)="","",VLOOKUP(…)) 처럼 한 번 더 감싸야 합니다. 이 도구로 저장하면 빈 칸은 빈칸 그대로 들어갑니다.

            다른 시트나 다른 파일에서 가져오려면요?

            같은 파일의 다른 시트면 범위 앞에 '단가표'! 처럼 시트 이름을, 다른 파일이면 '[단가표.xlsx]Sheet1'! 처럼 파일 이름까지 붙입니다. 다른 파일을 가리키는 수식은 두 파일을 함께 열어 둔 상태에서 넣어야 하고, 나중에 가져올 파일을 옮기면 연결이 끊깁니다. 이 도구의 「원본에 열 붙여 저장」은 수식이 아니라 값을 넣으므로 그런 걱정이 없습니다.

            이름이 같은 사람이 있어요 (다중 조건).

            「무엇으로 이을까요」에서 ＋ 조건 추가를 눌러 생년월일·연락처·부서처럼 한 열을 더 맞추세요. 조건을 모두 만족하는 줄만 가져옵니다. 엑셀 수식으로는 VLOOKUP 이 조건을 하나만 보므로 XLOOKUP(1,(이름범위=A2)*(생일범위=B2),가져올범위) 같은 식을 씁니다 — 수식 카드에 그대로 적어 드립니다.

            가져올 표에 같은 코드가 여러 줄 있어요.

            VLOOKUP 은 늘 맨 위 줄만 가져옵니다. 단가가 바뀌어 아래에 새 줄을 넣는 표라면 「맨 아래 줄」, 한 사람의 여러 거래를 더해야 하면 「합계」, 몇 건인지만 필요하면 「개수」, 여러 값을 다 보고 싶으면 「모두 이어 쓰기」를 고르세요. 결과의 「여러 개」를 누르면 그런 줄만 모아 봅니다.

            원본 파일의 서식이나 수식이 바뀌지 않나요?

            바뀌지 않습니다. 채울 표가 xlsx 파일이면 그 파일을 그대로 복사한 뒤 해당 시트의 맨 오른쪽 빈 열부터 값만 끼워 넣어 새 파일로 내려받습니다. 글꼴·테두리·병합·수식·다른 시트·그림은 손대지 않고, 원래 파일도 그대로 남습니다. xls·csv·붙여 넣은 표는 새 xlsx 로 만들어 드립니다.

            휴대폰에서도 되나요?

            됩니다. 메일·메신저로 받은 엑셀 파일을 고르면 같은 방식으로 이어 붙이고 저장합니다. 네이버·카카오톡 앱 안에서 열면 파일이 저장되지 않으니, 처음 나오는 안내대로 크롬이나 사파리로 옮겨 주세요.

            회사 명단을 넣어도 되나요?

            파일은 어디로도 전송되지 않습니다. 읽기·찾기·저장이 모두 이 브라우저 안에서 이루어지고, 페이지를 연 뒤에는 인터넷을 끊어도 동작합니다. 이 브라우저에 남는 것은 「너그럽게」 같은 고른 설정뿐이고 표 내용은 남지 않습니다.

            !쓰기 전에 확인하세요
            • 「너그럽게」는 다른 값도 같다고 볼 수 있습니다. 공백·형식·앞자리 0 을 같게 보므로 실제로 다른 코드(예: 「0123」과 「123」)를 이을 수 있습니다. 결과에서 「엑셀이면 #N/A」로 표시된 줄은 꼭 눈으로 확인하세요.
            • 붙인 열은 값입니다. 가져올 표가 나중에 바뀌어도 따라 바뀌지 않습니다. 계속 이어져야 하면 수식 카드의 VLOOKUP·XLOOKUP 수식을 쓰세요.
            • 수식은 참고용입니다. 엑셀 버전·국가 설정(인수 구분 기호가 ; 인 나라 등)에 따라 그대로 안 될 수 있고, XLOOKUP·TEXTJOIN·FILTER 는 엑셀 2021 이상이나 365 에서만 됩니다.
            • 개인정보가 든 표를 다룰 때는 결과 파일을 필요한 사람에게만 보내고, 공용 컴퓨터에서는 내려받은 파일을 지워 주세요. 이 도구는 파일을 서버로 보내지 않습니다.

            이 도구는 있는 그대로 제공되며, 결과 파일의 내용이나 사용 결과로 생긴 손해에 대해 제작자와 운영자는 법적 책임을 지지 않습니다. 중요한 자료는 원본을 따로 보관하고 결과를 확인한 뒤 쓰세요.
